# HOPE ホームページ

Driveのホームページ・体験ページのモックアップを基準にした静的サイトです。

## ページ

- `index.html` — ホーム
- `experience.html` — 体験トレーニング
- `assets/site.css` — 共通スタイル
- `assets/` — Drive内の写真素材

## ローカル確認

`index.html` をブラウザで開くか、このフォルダーでローカルHTTPサーバーを起動してください。

## GitHub Pages

GitHubリポジトリの Settings → Pages で、公開元を `main` ブランチの `/ (root)` に設定します。設定後、Pagesに表示されたURLからホームと体験ページを確認してください。

このサイトにはHOPEロゴを含めていません。CTAは電話リンクを使い、Web予約は未設定と明記しています。
